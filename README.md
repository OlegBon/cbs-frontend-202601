## ✨ Особливості (Features)

Окрім базового завдання марафону, в проєкт додано:

- **AJAX Contact Form**: Відправка повідомлень без перезавантаження сторінки (використання `fetch` + Formspree).
- **Валідація та UX**: Блокування кнопки при відправці, повідомлення про успіх/помилку.
- **SEO Optimization**: Налаштовано Meta Open Graph (для гарних посилань у соцмережах), додано `robots.txt` та `sitemap.xml`.
- **Custom 404 Page**: Власна сторінка помилки.
- **Favicon**: Налаштовані іконки для вкладок браузера.

## 📅 Прогрес марафону

- [x] **День 1:** Знайомство з Figma, налаштування середовища, структура файлів.
- [x] **День 2:** Header (шапка) та Hero section.
- [x] **День 3:** Адаптивна верстка (Mobile First).
- [x] **День 4:** Flexbox, вкладеність елементів.
- [x] **День 5:** Головний контент, робота із зображеннями (`picture`, `webp`).
- [x] **День 6:** Footer, навігація та соцмережі.
- [x] **День 7:** Фіналізація, секція постів.
- [x] **Bonus:** Розробка контактної форми (JS), сторінки 404, SEO налаштування.

## 🛠 Технології

- **HTML5**: Семантична верстка, SEO-теги.
- **CSS3**: Flexbox, медіа-запити, методологія BEM, CSS змінні.
- **JavaScript (ES6+)**: Логіка мобільного меню, асинхронна відправка форми (Fetch API).
- **Tools**: VS Code, Git, GitHub Pages, Formspree API.
