Цей проєкт розробляється в рамках 7-денного марафону по FrontEnd від CyberBionic Systematics. Мета - зверстати адаптивний сайт-портфоліо на основі макету з Figma.

## 🎨 Дизайн

Макет у Figma: [Personal Portfolio Design](https://www.figma.com/design/E2o98mCR2WhT2cabcXIs8c/-Publiched--EN--Personal-portfolio--Copy-?node-id=0-1&p=f&t=Y14VzvYMsvZ9f1gw-0)

## 📅 Прогрес марафону

- [x] **День 1:** Знайомство з Figma, налаштування VS Code, створення структури файлів (HTML/CSS).
- [ ] **День 2:** Створення Header (шапки) та Hero section (головного екрану).
- [ ] **День 3:** Адаптивна верстка (Mobile First/Desktop).
- [ ] **День 4:** Flexbox, вкладеність елементів.
- [ ] **День 5:** Головний контент, робота із зображеннями.
- [ ] **День 6:** Footer (підвал), навігація та соцмережі.
- [ ] **День 7:** Секція постів, пріоритетність селекторів, фіналізація.

## 🛠 Технології

- **HTML5**: Семантична розмітка.
- **CSS3**: Стилізація, Flexbox.
- **VS Code**: Середовище розробки.
- **Figma**: Робота з макетом.

## 📂 Структура проєкту

```text
/resume
  ├── index.html           # Головна сторінка
  ├── blog.html            # Сторінка блогу
  ├── featured-works.html  # Сторінка робіт
  ├── article-page.html    # Сторінка статті
  └── style.css            # Глобальні стилі
```
